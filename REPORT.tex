\section*{Project Objective}

This project reconstructs fully sampled T2 brain MRI slices from AF=5 undersampled k-space using the BraTS dataset. The assignment requires three tasks: undersampling simulation, a baseline reconstruction model, and a multi-modal unrolled model with data consistency.\\

\section*{Dataset and Preprocessing}

\begin{itemize}
\item Dataset path: \texttt{../bmeaidataset}
\item Modalities used: T1, T2
\item Slice axis: 2
\item Intensity normalization: z-score on non-zero voxels
\item Split strategy: patient-level train/validation/test
\item Slice selection for this run: 16 central slices per patient
\item Volume loading mode: preloaded in RAM to reduce I/O stalls
\item Split counts: train=6992, validation=1504, test=1504
\end{itemize}

\section*{Methods}

\subsection*{Task 1}

A 2D random variable-density sampling mask with acceleration factor 5 is generated in k-space. Fully sampled T2 slices are transformed with FFT, masked, and reconstructed with inverse FFT to obtain aliased images.\\

\subsection*{Task 2}

Task 2 uses a U-Net baseline with base channels 24, depth 4, batch size 8, MSE loss, and learning rate 0.0005. \texttt{ReduceLROnPlateau} is used for learning rate decay.\\
During training, \texttt{channels\_last}, pinned memory, non-blocking GPU transfers, TF32, and multi-worker prefetching are enabled to reduce GPU idle time.\\

\subsection*{Task 3}

Task 3 uses an unrolled U-Net with 2 cascades, data consistency layers, and multi-modal input consisting of aliased T2 plus fully sampled T1. The loss is \texttt{hybrid} with L1 weight 0.7.\\
